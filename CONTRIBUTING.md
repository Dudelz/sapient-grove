# 🤝 Contributing to The Sapient Grove

Thank you for your interest in tending the Grove.

This is not a typical software project. It is a living metaphor — a symbolic structure for ethical thought, resource modeling, and collaborative stewardship. All contributions must respect this intent.

---

## ✅ What You Can Contribute

- **Feature expansions** that add visual clarity or interpretive depth
- **Bug fixes** and code cleanups that preserve structure
- **New branch metaphors**, subcategories, or leaf dynamics that align with the Grove’s philosophy
- **Accessibility and clarity improvements** for both humans and AI collaborators
- **New narrative or symbolic elements** that enhance reflection and understanding

---

## 🚫 What You Should NOT Contribute

- Any logic that conceals imbalances, corruption, or excessive growth
- Code designed solely for commercial extraction or profit manipulation
- Obfuscation or removal of symbolic references and integrity tests
- Branding that replaces or dominates the Grove’s narrative
